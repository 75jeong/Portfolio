このポートフォリオは成果の大きさよりも「なぜそう決めたか」を中心にまとめています。どのプロジェクトも「問題定義 → リサーチ → 制約 → 決定 → 改善」の順に読めます。This portfolio focuses less on the size of outcomes and more on why I made each call. Every project reads in the same order: problem, research, constraints, decision, iteration.이 포트폴리오는 성과가 얼마나 컸는지보다 "왜 그렇게 결정했는지"에 초점을 맞췄습니다. 모든 프로젝트를 문제정의 → 리서치 → 제약조건 → 결정 → 개선 순서로 정리했습니다.
